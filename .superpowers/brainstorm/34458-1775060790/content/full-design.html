🔄 Two Pipelines
1️⃣ Ingest Pipeline (run once, refresh anytime)
📄 Sources
PluginHive docs · FedEx API docs
Google Sheets test cases · Playwright codebase
↓
✂️ Chunk & Clean
Split into 500-token chunks with 50-token overlap. Strip HTML, format code blocks.
↓
🔢 Embed
nomic-embed-text via Ollama
Fast, local, 768-dim vectors
↓
🗄️ Store
ChromaDB persisted to data/chroma_db/
Tagged by source (docs/code/tests)
2️⃣ Query Pipeline (every chat message)
💬 User Question
"How does label generation work?" or "Take me on a tour"
↓
🔄 Reformulate with History
LangChain rewrites question using chat history so "tell me more" resolves correctly
↓
🔍 Retrieve
ChromaDB returns top-5 relevant chunks from knowledge base
↓
