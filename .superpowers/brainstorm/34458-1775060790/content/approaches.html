3 Architecture Approaches

Pick the one that fits your ambition vs. build-time trade-off — I'll recommend at the end

A

Simple RAG — 1-2 days to build

1. Scrape docs → chunk → embed
2. User asks question
3. Find relevant chunks
4. qwen2.5:14b answers
✅ Pros
  • Fast to build
  • Very reliable
  • Easy to debug
❌ Cons
  • No memory — forgets previous questions
  • "What did I just ask?" breaks it
B

Conversational RAG ⭐ — Recommended · 2-3 days

1. Scrape docs → chunk → embed
2. User asks question
3. Reformulate with chat history
4. Find relevant chunks
5. qwen2.5:14b answers with memory
✅ Pros
  • Full chat memory per session
  • Follow-up questions work perfectly
  • "Take me on a tour" works!
  • Feels like real expert convo
❌ Cons
  • Slightly more complex than A
  • Long chats hit context limits
💡 This is the sweet spot — real conversation feel, not much extra complexity
C

Agentic RAG — Full power · 5-7 days

Domain Expert has tools:

🔍 search_docs(query)
📁 read_codebase(file)
📋 get_test_cases(feature)
🃏 get_trello_cards()
▶️ run_test(spec_file)
✅ Pros
  • Most powerful — can look things up dynamically
  • Can check live test status
  • Extensible with any tool
❌ Cons
  • qwen2.5:14b tool-calling is unreliable at 14b scale
  • Much harder to debug
  • Slow — each tool call = extra LLM round trip
⭐ My recommendation: Option B — Conversational RAG gives you "take me on a tour" + follow-up questions out of the box. We can add agent tools later in Phase 2.
