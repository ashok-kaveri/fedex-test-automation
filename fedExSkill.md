# FedEx Test Automation — Expert Guide

## Project at a Glance

- **Stack:** Playwright 1.58.2 + TypeScript, targeting FedEx Shopify App
- **Pattern:** Page Object Model (POM) with custom `Pages` fixture
- **Execution:** Fully serial (`fullyParallel: false`, 1 worker)
- **Auth:** Cookie/session reuse via `auth.json` (generated by setup project)
- **App UI:** All FedEx app content lives inside `iframe[name="app-iframe"]`
- **Test target:** Shopify admin → FedEx embedded app

## Writing a New Test

Every test file follows this exact structure — don't deviate from it:

```typescript
import { test, expect } from '../../src/setup/fixtures';
import ShopifyOrderUploader from '../../src/helpers/createOrder';

const store = process.env.STORE;

test.describe.configure({ mode: 'serial' });

test.describe('Feature Name', { tag: '@smoke' }, () => {
  let sharedOrderID: string;
  let orderUploader: ShopifyOrderUploader;

  test.beforeAll(async () => {
    orderUploader = new ShopifyOrderUploader();
    sharedOrderID = (await orderUploader.uploadOrder()) as string;
    expect(sharedOrderID).toBeTruthy();
  });

  test('1. Navigate to order', async ({ pages }) => {
    test.setTimeout(60000);
    await pages.shopifyAdmin.navigateToStore(store);
    await pages.shopifyAdmin.searchAndOpenOrder(sharedOrderID);
  });

  test('2. Generate label', async ({ pages }) => {
    test.setTimeout(120000);
    await pages.manualLabelPage.generateLabelInApp();
    await expect(pages.orderSummaryPage.packagesSection).toBeVisible();
  });
});
```

**Key rules (enforced by ESLint):**
- Import `test` and `expect` from fixtures, NOT from `@playwright/test`
- Use `{ pages }` fixture — never call raw `page.*` methods directly in tests
- Every test MUST have at least one `expect()` assertion
- Never use `page.waitForTimeout()` > 3 seconds — use `expect()` with timeout instead
- No `test.only()` — blocked in CI
- Use `test.describe.configure({ mode: 'serial' })` in every describe block

## The `Pages` Fixture

Provides all page objects via `async ({ pages }) => {}`. Available pages:

| Property | Class | Purpose |
|---|---|---|
| `pages.sharedPage` | `Page` | Raw Playwright page (use sparingly) |
| `pages.shopifyAdmin` | `ShopifyAdminPage` | Navigate Shopify admin, search orders |
| `pages.shippingPage` | `ShippingPage` | Order list, label status, request pickup |
| `pages.manualLabelPage` | `GenerateLabelManuallyPage` | Generate labels manually |
| `pages.orderSummaryPage` | `OrderSummaryPage` | View generated label summary |
| `pages.pickupPage` | `PickupPage` | Pickup request flow |
| `pages.returnLabelPage` | `ReturnLabelPage` | Return label generation |
| `pages.packagingSettingsPage` | `PackagingSettingsPage` | Box/packaging configuration |
| `pages.additionalServices` | `AdditionalServices` | Additional service settings |
| `pages.productsPage` | `ProductsPage_M` | FedEx app products list |
| `pages.shopifyProductPage` | `ShopifyProductPage` | Shopify product admin |
| `pages.productPage` | `ProductPage` | Individual product in FedEx app |
| `pages.sideDockPage` | `SideDockPage` | Manual label side configuration |
| `pages.authPage` | `InstallationAuthPage` | App installation auth |

Fixture scope is `worker` — all page objects are shared across tests in a suite.

## Creating a Page Object

All page objects extend `BasePage`. Locators MUST be `readonly` properties in the constructor (ESLint enforces this — no locators inside methods):

```typescript
import { Page } from '@playwright/test';
import { BasePage } from '../basePage';

export class MyNewPage extends BasePage {
  // Locators defined in constructor as readonly
  readonly myButton: Locator;
  readonly myInput: Locator;

  constructor(page: Page) {
    super(page);
    // App iframe locators use this.appFrame
    this.myButton = this.appFrame.getByRole('button', { name: 'Submit' });
    this.myInput = this.appFrame.getByLabel('Tracking number');
    // Shopify admin locators use this.page
    this.shopifyThing = this.page.getByRole('link', { name: 'Orders' });
  }

  async doSomething() {
    await this.myButton.click();
    await this.waitForLoadingToComplete();
  }
}
```

**Key `BasePage` utilities available in every page object:**

```typescript
this.appFrame                          // FrameLocator for iframe[name="app-iframe"]
await this.waitForLoadingToComplete()  // Wait for spinner to disappear
await this.clickAppButton()            // Click FedEx app nav link
await this.selectAppMenu(route)        // Navigate app sidebar menu
await this.expectToast(message)        // Assert toast notification
await this.downloadLogs(action)        // Download app logs as ZIP
this.calculateVolumetricWeight(L,W,H,unit)
```

After creating a page object, register it in `src/setup/fixtures.ts`:
1. Add it to the `Pages` type
2. Instantiate it in the fixture's page factory

## Order Creation

Use `ShopifyOrderUploader` in `test.beforeAll` to create test data via the Shopify API:

```typescript
// Simple order (US address, single simple product)
const uploader = new ShopifyOrderUploader();
const orderId = await uploader.uploadOrder();

// Order to UK address
const orderId = await uploader.uploadOrder('UK');  // 'UK' | 'CA' | default US

// Order with specific products
const orderId = await uploader.uploadOrderWithMultipleProducts(
  [
    { productType: 'simple', productIndexes: [0], quantities: [2] },
    { productType: 'variable', productIndexes: [1], quantities: [1] }
  ],
  'CA'  // optional country
);

// Get last created order ID
const lastId = uploader.getLastOrderId();
```

**Product types:** `'simple'` | `'variable'` | `'digital'` | `'dangerous'`

Products are mapped per-store in `testData/products/productsconfig.json`. The store is read from `process.env.STORE`.

## Authentication

Auth runs once as a `setup` project before all tests:
- Navigates to Shopify admin, handles CAPTCHA manually (120s pause), saves session to `auth.json`
- All tests consume `auth.json` via `storageState` in `playwright.config.ts`
- If `auth.json` is stale/missing, delete it and run: `npx playwright test --project="setup" --headed`

**CAPTCHA:** When detected, the test pauses and prints a message asking you to solve it manually in the browser window. It waits up to 2 minutes.

## Common Patterns & Anti-Patterns

### Do this

```typescript
// Wait using expect (not waitForTimeout)
await expect(pages.orderSummaryPage.successBanner).toBeVisible({ timeout: 30000 });

// Use page object methods
await pages.shippingPage.searchOrderWithRetries(orderId);

// Locators in constructor
readonly submitBtn = this.appFrame.getByRole('button', { name: 'Submit' });
```

### Don't do this

```typescript
// ❌ Raw page calls in tests
await pages.sharedPage.click('#submit');

// ❌ Hard wait
await page.waitForTimeout(5000);

// ❌ Locator defined inside a method
async doThing() {
  const btn = this.appFrame.getByRole('button', { name: 'Submit' }); // ESLint error
  await btn.click();
}

// ❌ Import test from @playwright/test
import { test } from '@playwright/test'; // Must use fixtures!
```

## iframe Handling

The FedEx app runs inside an iframe. Always use `this.appFrame` (a `FrameLocator`) for app content:

```typescript
// In page objects — app content
this.appFrame.getByRole('button', { name: 'Get Rates' })
this.appFrame.locator('[data-testid="package-row"]')

// Shopify admin content (outside iframe)
this.page.getByRole('link', { name: 'Orders' })
```

Never try to locate app elements directly on `this.page` — they won't be found.
